    How the workbook is laid out

    • A Summary tab with counts per program, and an All Programs tab with every row.
    • One tab for each DDF program.
    • A Not Pooled (Excluded) tab for 8 partnerships checked and left out, such as the 2020 five-foundation payout pledge, where each foundation spent its own money.
    • Each row gives the co-funders, the organization that ran the program, years, status, DDF's contribution, total pool size, a description and source links, rated High or Medium confidence.

    Things to know before relying on it

    • 15 of 40 rows are Medium confidence: some details come from search-result summaries because several sites blocked automated reading.
    • A few rows count as shared funding only loosely (for example the Cumberland Forest Project is a co-investment); the "Pool Type" column says which is which.
    • Older programs may be under-counted: DDF rebuilt its website and many older press releases now return "page not found".
    • Not fully searched: Arts collaborations with the Wallace Foundation and a few other Arts leads.
    • The Summary counts are formulas that fill in when the file is opened in Excel.

  4. Prompt 4

    Write a small Python script that builds data.json (and a data.js so the page works when I double-click it) from the research files.

    Summary of reply

    Added build_data.py, which reads both research files and writes identical data.json and data.js (the latter sets window.DDF_DATA so a double-clicked page can load it).

    I added build_data.py. Run python build_data.py from the project folder to create both files.

    • data.json is for a page served from a web server (fetch("data.json")).
    • data.js sets the same data as window.DDF_DATA, so a page opened by double-clicking can load it with a plain script tag. It uses only ASCII, so accented names show correctly even if a page doesn't declare its character set.
    • network: the 13 pooled programs and 80 funders plus DDF, with endowments and websites. international: the 9 programs abroad, 23 funders including DDF, 34 program–funder links and 22 countries; each program carries its funder IDs and country codes.

    The script reads the spreadsheet by column name, stops with an error if a link or country points to a program or funder that doesn't exist, and works out the count columns itself because Excel formulas in the workbook have no saved results.

Choose shades that remain distinguishable for people with color-vision deficiencies. - Add a legend for program-area colors, node-size tiers, pale nodes for missing endowment data, and dotted lines for missing funding amounts. Filters and controls - Add a program-area filter and a Grant Programs dropdown. - Selecting a program should highlight its funders and open an information panel on the right. - Add a year filter with a Play button. While the timeline plays, show the current year in large, light-gray text in the top-left corner. - Add `+` and `−` zoom buttons and support scroll-to-zoom. Keep label text the same size as the graph zooms. - Add a Reset button that clears all filters, selections, highlights, and the information panel. Interactions - When a user hovers over a funder, dim unrelated nodes and links and highlight that funder and its connected nodes. Show a tooltip listing its programs. - Reduce label clutter: always show labels for DDF, larger funders, and funders with more than one program. Show other names on hover or when the user zooms in. - When a user clicks a funder, show an information panel on the right with: - Endowment - Website link - Number of DDF programs - For each program: program area, year, amount, what the amount represents, number of other funders, and a source link Searchable lists - Show buttons labeled “80 funders” and “13 grant programs” in the graph’s top-right corner. - Clicking either button should open a searchable list in the right-side panel. - Order the funder list by number of programs, then alphabetically.     Summary of reply

    Built index.html: a D3 force-directed network of the 13 programs and 81 funders with every requested filter, panel, list and legend, using colors checked with a palette validator for color-vision deficiencies, and tested in the browser.

    I built the network page, index.html, and tested every feature in the browser at 1440×900 with no console errors. It uses only the research data; missing endowments, amounts and sources show as "not found" or "Not available".

    How it looks

    • Layout: funders sit around invisible anchor points, one per program, so each program forms its own cluster.
    • Links: DDF links are colored by program area, with width showing the program amount, and dotted where the amount is missing. Links between co-funders are thin and faint.
    • Nodes: size follows the four endowment tiers; funders with no endowment figure are small and pale; funders in several areas are drawn as a pie.
    • Colors: red #be395e, orange #d37e07, green #46ac71, blue #2579ab. The first red and green were too similar for red-green colorblind viewers, so combinations were tested with a palette validator until every check passed (worst colorblind pair ΔE 9.4, target 8).
    • Labels: DDF, funders over $1B and funders in more than one program are labeled unless labels would overlap; others appear on hover or zoom, and stay the same size as you zoom.

    Everything else works: the area filter, Grant Programs dropdown, year slider with Play and the large year, zoom buttons and scroll-to-zoom, Reset, hover dimming with tooltips, info panels, and the searchable "80 funders" and "13 grant programs" lists with a back button. Two additions: the graph pans so highlighted funders aren't hidden behind the panel, and the legend is collapsible.

    The page loads D3 from a CDN, so it needs an internet connection even when opened by double-click; data.js loads locally.

    Summary of reply

    Added the programs-abroad layer (off by default), the Where funds go and Countries filters, clickable country chips, dashed rings for funders with programs abroad, and a world map below the graph; the layer turns on automatically and Reset turns it off.

    What's new

    • Programs-abroad layer: a toggle, off by default, adds the 9 programs and 19 new funders (99 funders and 22 programs in total). Funders with a program abroad get a dashed ring, explained in the legend. The US network stays where it was; new clusters appear around its edge.
    • Where funds go: US only = the 13 original programs; International = funded work only abroad (the four health programs in Africa); Both = the five that also funded US work.
    • Countries filter: searchable multi-select grouped by region, with each country's program count.
    • Country chips in each program's panel filter by that country.
    • World map below the graph, shaded by how many programs match the filters; clicking a country filters by it; the filter and the selected program's countries are outlined.
    • The layer turns on automatically for International, Both, a non-US country or a program abroad; Reset turns it off.

    Decisions

    • Building Bridges uses a fifth color, a violet #b770e6, which passes the colorblind check with the other four.
    • The timeline uses the first year in each program's date range; amounts abroad use the headline figure in the research text ("~" marks an estimate).
    • The research workbook gained Also Funds US Work and US Work Evidence columns, which the Both category needs; build_data.py reads them and adds map codes for each country.
    • The toolbar was rearranged so it doesn't wrap, and crowded labels now try above or to the right of their node before being hidden.
