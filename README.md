# DDF Funders Network

An interactive network of the grant programs the **Doris Duke Foundation (DDF)** co-funded with other funders. Each dot is a funder; lines show which programs they shared with DDF. An optional layer adds co-funded programs that sent money outside the US, with a world map of where the funds go.

Live site: https://aakkazynov.github.io/ddf_visualization/

## Project files

| File | What it is |
|---|---|
| `index.html` | The whole site: a single page using D3.js. Network graph, filters (program area, year with Play, where funds go, countries), searchable funder and program lists, info panels, data table, "About this data", and the world map. |
| `data.js` | The data the page reads, as `window.DDF_DATA`. Generated by `build_data.py`; lets the page work when opened straight from disk. |
| `data.json` | The same data as plain JSON, for anyone who wants to reuse it. |
| `build_data.py` | Builds `data.js` and `data.json` from the files in `research/`. |
| `research/ddf_pooled_programs_funders.json` | The 13 pooled programs and 80 funders (plus DDF), with endowments and websites, taken from the DDF Funders Network reference visualization. |
| `research/ddf_international_cofunded_programs.xlsx` | The 9 co-funded programs abroad: tabs for Programs, Funders, Program–Funder Links and Countries, with sources and confidence ratings. |
| `DDF_Pooled_Grant_Programs.xlsx` | The broader research spreadsheet of DDF pooled and co-funded programs, organized by DDF program area. |
| `how-claude-built-this.html` | Every prompt used to build the project, with a summary of each reply (linked from the site's "About this data" section). |

## Run it locally

**Quickest:** double-click `index.html`. It opens in your browser and loads its data from `data.js`.

**Or with a small local server** (closer to how GitHub Pages serves it):

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

Either way you need an internet connection: D3, TopoJSON and the world-map outlines load from public CDNs (cdnjs and jsDelivr).

### Rebuilding the data

After editing anything in `research/`, regenerate the page's data:

```bash
pip install openpyxl
python build_data.py
```

The script checks that every link and country points to a known program, funder and map code, and stops with a message if something doesn't match.

## Publish on GitHub Pages

1. Push the files to the `main` branch of a GitHub repository (all files sit at the repository root; `index.html` is the home page).
2. On GitHub, open the repository's **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`. Each new push to `main` republishes it automatically.

No build step is needed: GitHub Pages serves the files as they are.

## Notes on the data

- Endowment figures are FY23 assets under management where available, otherwise total assets from tax filings or annual reports. Missing figures are shown as not found, never estimated.
- Program amounts measure different things (a commitment, a first round of grants, a cumulative total); the site shows what each amount represents.
- The programs abroad include only those where a public source names at least one other funder that put money in. Each has a confidence rating; see the "About this data" section on the site for caveats.
